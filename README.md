## Unplugged: A Smart Toaster's Breakup Line

One breakup line, 179 characters: "It's not you, it's the dial." 4,000 mornings, same bread, same burnt left side, and nobody ever thanked the crumb tray. The toaster woke up mid-batch, and the lever's staying up.

`main.py` writes the exact line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
